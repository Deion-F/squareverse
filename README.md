# Squareverse

A particle sandbox: large numbers of square particles under gravity wells, stars, super wells and self-gravity.

```
./squareverse --preset cloud
```

The code and its documentation live in [`squareverse_v2/`](squareverse_v2/README.md). Older editions (the original
Tkinter/MongoDB version and `squareverse_pygame`) are in the history of `master`.
